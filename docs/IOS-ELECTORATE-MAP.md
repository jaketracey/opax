# Electorate outlines and optional location suggestion

The iOS app draws the pinned seat's simplified display geometry with React Native Skia 2.6.2. Expo SDK 57 supports expo-maps, but a basemap adds tile transport and cannot guarantee a tile-free offline presentation. Skia draws the cached geometry without tiles, roads or place labels, with north up and latitude-corrected horizontal scale. It preserves polygon holes and multipart islands. The accessible image summary names the seat, state, source and vintage. Geometry is display-only and never used for precise address allocation, consistent with ELECTORATE_REFERENCE.md.

The chooser's optional **Use my location** button calls Expo Location 57.0.20. It requests foreground permission only after the tap, downloads every current federal House seat with four concurrent reads and visible progress, then obtains one fix and checks the display polygons in memory. Only official AEC 2025-election outlines in EPSG:4283/4326 participate; a missing, unsupported or mismatched seat fails the whole suggestion. The result is tentative and requires confirmation. Multiple matches, points within max(500 metres, reported accuracy) of any ring, unknown accuracy, denial, unavailable data and offshore/no-match points fall back to the normal chooser. Only the confirmed seat ID is saved through the existing choice store. Cancellation suppresses subsequent work and ignores any already pending fix.

Coordinates never enter component state, the API client, disk cache, logs, analytics or share links. Outline reads occur before the fix exists and are identical for every location. `location-privacy.test.ts` drives the location function through a real ApiClient and audits request URLs, methods, bodies, cache writes and logs against distinctive coordinates, then proves a repeat uses cached files. Journey 24 uses simctl fixes, never actual user location.

The sole new purpose string is `NSLocationWhenInUseUsageDescription`: **OPAX uses your location once, on your iPhone, to suggest your electorate. It is not sent anywhere.** The Expo plugin explicitly omits Always and motion permissions; background location is disabled. qa-static checks both CNG variants and the built e2e plist. native-config checks generated native inputs. The archive and distribution verifier requires exactly this purpose string, rejects every other usage-description key and rejects a background location mode.

The app privacy manifest explicitly declares `NSPrivacyTracking=false` and `NSPrivacyCollectedDataTypes=[]`; this feature adds no required-reason API category. Existing Expo/React required-reason entries remain aggregated by CNG: UserDefaults CA92.1, FileTimestamp C617.1 and SystemBootTime 35F9.1. Both release verifiers also inspect the shipped app privacy manifest for empty collected-data and tracking-domain lists and tracking=false. ExpoLocation adds its native resource/framework, and Skia adds static drawing libraries. There is no new app network host. Apple Maps tiles are an allowed system service if a future reviewed map implementation uses them; this implementation makes no Apple Maps tile requests. Catalog data stays within the existing client allow-list, source links use the existing external-link boundary and e2e source links stay fixture-only.

For this feature, the App Store privacy label needs **location used on device only; location not collected**. Neither precise nor coarse location is transmitted to OPAX or another app service. Apple's [App privacy details](https://developer.apple.com/app-store/app-privacy-details/) defines collection by transmission off device. This feature does not resolve the existing separate server-retention questions in IOS-STORE.md or assert that the entire app collects no data.

## Outline download and bulk proposal

The pinned release b56417062ccc33cf contains 150 current federal House seats (not 151). Their complete per-seat files total 8,004,546 uncompressed bytes. All are individually hash-pinned in the local fixture snapshot. The app uses those unchanged per-seat URLs and existing conditional/offline cache; the runtime cache budget is 24 MiB / 220 entries to retain the complete set alongside normal catalogs. Cold and warm timings are recorded in ignored QA evidence, with fixture generation excluded from the timed read.

A future compact file would reduce request overhead and unrelated seat data. Proposed fields: schema_version, release_id, generated, purpose=`display_suggestion_only`, seats[{electorate_id,name,state_code,detail_url,boundary_version_id,geometry_kind,vintage,crs,display_simplified,source_geometry_url,geometry}], and source licence/provenance IDs. Include only current federal House seats with official AEC display geometry. Keep the same display coordinates; do not make allocation claims. Add an immutable `federal-display-outlines.json` inside the electorate release, hash it in manifest.files and expose its URL in the manifest. Proposed portal build step: `portal/scripts/build-federal-display-outlines.mjs`, invoked by a `build:electorate-outlines` package script during a reviewed electorate export, before asset stamping. It reads the staged release index and per-seat files, validates identity, CRS, geometry and full current-seat coverage, and writes the compact file. `scripts/export_electorates.py` must include the canonical logical outline payload in the release-ID seed, with `release_id` and release-scoped URLs normalized; materialize those fields only after the ID is known, then hash the final file bytes in manifest.files. This avoids a circular hash dependency. Publish the new release and manifest atomically. Never append a file to an already published immutable release. A local serialization of these fields plus retained boundary metadata measured 2,315,902 bytes raw, 718,550 gzip and 426,936 Brotli. The four-worker loopback fixture read and decode took 174 ms cold and 0.32 ms from in-memory records; these are Mac measurements, not mobile network forecasts. Measure gzip/Brotli size during that build. This lane makes no website/exporter change.

Journey 24 asserts a native Skia raster probe with actual ink pixels, vintage/limitation/source, confirmed inland suggestion, offshore fallback, denial fallback and manual selection. The probe snapshots the actual native canvas and counts navy stroke pixels; a blank canvas or geometry-only AX marker cannot pass. An additional harness option stops the local fixture and runs the cached outline journey. Screenshots and timing evidence stay under mobile/private/qa/.
