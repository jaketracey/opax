# Clear grant discoveries

The current grant films show an interaction before the screen explains its result. The product should explain a specific award without requiring map literacy.

Use existing Opax tokens: paper #FAF9F6, white #FFFFFF, ink #23271F, secondary ink #575C52, navy #142A43, bronze #8A5A12. Merriweather headings and Public Sans controls retain the site's identity. Left-align prose; keep descriptions below 70 characters per line.

Layout: title and short purpose; three real project starting points; search and collection controls; for historical records, a labelled year control and the names of awards first published that year; a selected project with purpose, recipient, amount, publication date and original source alongside its actual location. On mobile the explanation comes before the map. Never open with an empty instructional card when a verified project is available.

The memorable element is a legible, concrete project explanation, not extra decoration. Motion only answers a selection. Timeline changes name the added records and quantify excluded later records. Award values remain current notice values, not reconstructed historical payments. Invitations stay separate. Shared URLs retain the selected project and filters. No new model calls or invented project claims.

Review: keep the map as supporting location evidence, not the sole output; no artificial count-ups, autoplay or decorative motion. Preserve source links and inaccessible-location states. Verify keyboard, narrow widths, filtering, year cutoffs, query links and multi-site totals.
