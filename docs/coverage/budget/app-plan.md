# Budget app surface — plan only

Keep `/budget` on the web for the current read-only app scope. Add a signed-out **Federal budget papers** link under the public record/catalogue links, opening the sourced web hub in the system browser. Budget figures do not belong on an MP profile, and they do not imply how a person voted or caused a fiscal result. The existing app contract excludes the web money map and Explore; this proposal does not add a native Money tab or expand its paid-route allowlist. See [app scope](../../IOS-APP.md) and [API contract](../../IOS-API-CONTRACT.md).

A later native catalogue can fit alongside Bills and Registers: financial-year list → release picker (Budget, MYEFO, Final Budget Outcome) → aggregate table and original-paper reader link. It must show estimates, projections and reported actuals separately, including the March/October 2022 distinction and revisions to actuals. Each figure retains the original units, document/table/page, acquisition snapshot, SHA-256 and applicable document licence/exceptions. Native charts use the app's design tokens, with accessible numeric tables and missing actuals left missing.

Before that native screen ships, review and promote a versioned, licence-gated budget manifest through the nightly data path; add its static read to the app's explicit public-data allowlist and validate its schema, hashes and offline cache. Do not send budget reading through Ask, generation, voice, document search, remote link-preview fetches or identity joins. Private individuals get no profiles. No app code, API contract change, app build or simulator run is included in this lane.
