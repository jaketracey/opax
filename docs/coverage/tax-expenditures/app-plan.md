# App surface — plan only

No native app, simulator, app contract or app manifest changes are included.

After orchestrator review, explicit promotion and web deployment, a first app surface could link to `/register/tax-expenditures` under Money → Public money. A native list would need a separate bounded, versioned read-only contract carrying statement year, item ID, measure year, revenue-forgone basis, benchmark, published value/code, status, source locator, snapshot, hash and licence.

Keep the statement vintage distinct from measure years and forward estimates. Preserve negative values and every nil/unquantifiable/withheld/rounding code. Include Treasury's combined estimates as explicitly identified published groups; never calculate item/category/year totals. Reuse the published source and licence notices, and include no private-person identities or joins. Native work remains a later reviewed lane.
