# South Australian historical budget: app plan only

No native code, app API, simulator, release or app behaviour is changed or claimed.

After independent review and explicit annual promotion, link the app’s existing
budget entry to `/budget#sa-budget`. Label it **South Australia · 2015–16 historical
Budget**, with “Not the current budget” in the description. Keep the federal
budget and ABS government-finance entries distinct.

A later native table can reuse the reviewed cell contract: resource UUID,
workbook/sheet/cell, fiscal year, source estimate/actual label, displayed and
stored values, units, basis, vintage, snapshot, source SHA-256 and CC BY 4.0
attribution. Use the money house style, show published dashes separately from
zero, and offer the original resource link and correction contact.

The function workbook remains an explanatory source link with its verbatim
interest/non-reliance/revision warning. Do not display its held amounts, infer
units, add totals, merge it with ABS, or create person entities. A new reviewed
source finding must resolve units and the five reconciliation exceptions first.

No Ask, generation, voice or authentication workflow forms part of this plan.
Annual manual promotion stays outside nightly.
