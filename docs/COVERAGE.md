# OPAX coverage map

Checked **8 October 2026**. Intent: “record everything in government”. This is an inventory of the requested parliamentary, executive and electoral record families across the Commonwealth, six states and two territories, and a queue for expanding them. It is not a claim that OPAX holds every government record. Local government, courts, departmental operational records, annual reports, regulations outside FRL, public datasets, archives and government-owned corporations also need separate inventories.

**Status:** `covered` would require an evidenced complete, clearly bounded series; `partial` means some records, years, fields, jurisdictions or public projections are missing; `not yet` means no verified dedicated published series. No broad record family below is certified complete. An ingest script alone is not proof of holdings. Research-only retained data is marked partial with surface none, not publicly covered.

**Counts:** source rows, searchable resources, document versions, vote participations and public export entries have different grains. Never add them together. Dates and counts below belong to the cited snapshot; no production database was queried. Every external link included here returned HTTP 200 to an ordinary GET on 2026-10-08 after a robots check. The URL receipt ledger is below. A 200 landing page proves reachability, not dataset completeness or permission. Source registries are repo links when a direct publisher URL could not safely be verified; these cases are explicitly marked and remain source-discovery work.

**Surfaces:** web routes are evidenced by repo dispatch/export code; only `/stats`, `/methods` and the public manifest were read live. App screens are **planned contract surfaces**, not verified shipped/native behavior: see [iOS API contract](IOS-API-CONTRACT.md). This lane ran no app, simulator or native build.

## Snapshot and evidence

Live OPAX stats [source][S73] and OPAX methods [source][S74] returned the public site shell. `/stats` loads its source table from the manifest and live counts client-side; no live-count API was called. The methods page explains the 200-character filter, procedural removal and source-first citation. Its prose says NSW/VIC “from 2015”; the manifest distinguishes **VIC 2018**. Methods’ AGPL notice is a code licence, not a blanket data licence.

## Next

Scoring is a research judgement, **public interest × data availability × licence clarity**, each 1–5, maximum 125. Interest: 5 = major national spending/law/accountability, 4 = strong jurisdictional accountability. Availability: 5 = official structured API/download and stable IDs, 4 = stable HTML/tables or machine-set files, 3 = heterogeneous files, 2 = incomplete access, 1 = blocked/no lawful automated path. Licence: 5 = explicit applicable open grant, 4 = open publication policy with document exceptions, 3 = partial/scope uncertainty, 2 = no applicable grant established, 1 = restrictive. Ties favour breadth, then cost. Scores are not licence approval; **licence checked before any ingest** applies even at 5.

Every recommendation shares these guards: **public records only; original source, snapshot and licence shown; no profiles, name-search entities, donor/lobbyist/witness identity nodes or cross-record identity joins for private individuals; non-partisan descriptions; licence checked before any ingest.** Public officials may be identified in their official role. Private names can remain only inside the authorised source record, subject to the publication review. Preserve redactions, corrections, source hashes and record/version IDs. Never bypass a challenge, ignore terms/robots, send requests to people, or publish a provisional match.
