# OPAX Ask agentic routing — fix 1, 21 October 2026

All six review findings fixed and committed for review. **Hold production: no push, deploy or production Ask/generation/voice/auth request.**

Implementation commit: `b9e2a6ac8334560fb9e8c79b9dec814b9e0cea78` (on `web/ask-agentic-routing`). This report follows in a separate documentation commit. Baseline remains detached origin/main `8d61ed9704368e5996a3761e7feb8c75df8d7270`, with no baseline commits.

## Six findings and regressions

Each finding was reproduced by a failing offline regression before its implementation changed; the initial red-run evidence is retained locally.

1. **SSE period leak:** dated fallback and cached replay suppress unvalidated deltas and release the validated final payload; wrong-period figures and their auxiliary fields are removed. `ask-fallback-period.test.mjs` covers JSON, chunked LF/CRLF SSE and replay; `research-route.test.mjs` exercises a real ordinary-cache HIT replay with a poisoned current-salary answer.
2. **Calculated money bypass:** explicit question dates override stale UI controls in calculators and ordinary fallback, including follow-ups; calculated receipts now expose observed and requested financial-year coverage and export as-of. Both loop and fallback compare actual coverage, rather than trusting a calculated flag or matched boolean. Regression tests cover stale `from/to=2024` for mining in 2005, JSON/SSE, mismatched coverage, and forced loop failure.
3. **Historical chamber:** `paidAnswer` forwards explicit/natural-language chamber, party and jurisdiction to `datedPay`. Senator-in-2005 tests with/without the senate filter return the documented historical-membership limitation and no Prime Minister or salary figure.
4. **Rounding classification:** `pay-history.ts` uses exported remuneration classes and the spell-ending entitlement, without role-title keyword tests. All **2,716 spell-ending rates** and **226 current rows** reconcile. Synthetic role tests cover the 35% rate (207,100 × 1.35 = 279,585) and ambiguous classification; if both classes fit the stored rate but disagree at the requested date, the calculator explicitly declines to guess.
5. **ACT detection:** only ACT, A.C.T., the full territory name or jurisdictional Canberra context select ACT. The two reviewed ordinary-act/statute questions and all affirmative territory variants have regression coverage.
6. **Open dates:** ISO dates and years preserve inclusive since/until, exclusive before/after and inclusive between semantics. Tests cover all ten forms, plus clearing stale opposite tool bounds and validating upper-only coverage.
