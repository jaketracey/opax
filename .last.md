## Routing order

**Before, as verified on this origin/main:** network/body guards → route selection → immediate receipt ranking → immediate current-pay calculation → named scope/cache/quota → research, with electorate questions taking a deterministic plan outside research. The classifier/kind gate was already conditional on loop being off; it did not restrict ordinary questions when `RESEARCH_LOOP=route`.

**After:** network/body guards → route selection → scope/cache/quota → agent research → read-only calculated/lookup/search tools → deterministic constraint and citation checks → agent fact/point selection → JSON/SSE response. Loop failures keep the existing bounded numerical/ordinary fallback, with a final temporal check. Explicit years override stale current/all UI filters on the loop route; follow-ups retain conversation and inherit periods. Calculated pay/receipt answers and private or wholly uncited turns are not stored in the loop cache.

The model and configured provider remain DeepSeek v4.1 Flash on Together. Existing research wall, token, generation-minute and atomic daily-USD reservations, credit cooldown, cancellation and reader quota remain in place. The 16 October contract is retained: soft failures keep points uncited; hard attribution, causation, privacy, SA-placeholder and explicit temporal boundaries remain enforced. Donor disclosure/identity matching is unchanged.
