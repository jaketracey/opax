## Trace and fix

- `research-calculated.ts` placed the complete calculator answer in one citation label; `factSheet()` treated that whole block as a single selectable fact. Individual `parliamentary_pay` results supplied the same salary rows separately.
- `research-loop.ts` returned a selected complete calculator payload unchanged when it was the only fact. With overlapping selections, `compose()` pasted the entire block alongside individual rows. Its exact-string deduplication could not recognise overlapping rows or reversed blocks. The initial detached-baseline reproduction shows both salary steps, the same steps again, extra officials and a second coverage paragraph.
- The bounded ordinary fallback also returned `paidAnswer()` / `rankedMoneyAnswer()` before generation. `research-response.ts` added metadata and period checks; it did not create the duplication. JSON already contained it. SSE and cached replay carried the same body.
- The agent now selects evidence first. The same pinned model writes record answers from deduplicated fact atoms. Figures, entity/metric ownership, dates in both month orders, quotes and citations are checked. Unsupported numeric clauses or sentences are removed under the 16 October contract. Already verified passage points and loose uncited survivors are preserved.
- A failed, timed-out or unadmitted writer uses explicit pay, money and count prose templates. The templates parse record rows, discard calculator boilerplate, and include at most one coverage sentence. Full-block calculator titles do not classify every underlying fact as coverage. Coverage declines are graded as declines. The final old 2005 example below reproduces the reported duplicate twice, directly in JSON.
- Ordinary fallback prose also removes duplicated sentences and overlapping financial amounts, including a repeated amount beside a new figure, rebasing Unicode citation spans and unciting dropped-only sources. The loop fallback cannot auto-select an instant calculator. Both cache keys include the writing version; cached replay returns the completed payload. Fallback SSE withholds deltas until the done payload has passed the guard. Period, chamber, ACT, Tencent Singapore/network, moderation, privacy and budget guards remain in place. No model or provider configuration changed.
