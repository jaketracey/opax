# Bundled fonts

Unmodified upstream static TrueType fonts, retrieved 3 October 2026.
Runtime aliases (`src/design/tokens.ts` `fonts`): Merriweather,
Merriweather-Bold, PublicSans, PublicSans-SemiBold and PublicSans-Bold. OFL
notices accompany each family. No conversion or font modification is used.
Merriweather publishes no static SemiBold, so section headings use Bold where
the web uses weight 600; instancing the variable font would modify a font with
a Reserved Font Name.
