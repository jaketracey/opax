# OPAX demo recorder

Browser capture is paused under [the source-access policy](../../docs/SOURCES-ACCESS.md).
Existing recordings and their evidence remain on disk. Automated browsers are
restricted to OPAX UI tests. The command launcher and `record.mjs` no longer
install or launch a browser, or acquire any source.

The scene descriptions, overlay helpers, video rendering helpers and prior
recordings are retained for future approved work.
